* 0.9.1 — 2026-10-19

** Fixed

- The jump reader\='s annotations could fail with an error when
  bookmark-gt was installed from MELPA and marginalia was
  installed afterwards.
- ~bookmark-gt-tags-alist~ could fail with

* 0.9.0 — 2026-10-17

The release after 0.2.0.  There is no 0.3.0.

** Breaking — read before upgrading

- ~bookmark-gt-set~ is removed.  Use ~bookmark-gt-create~ to make
  a bookmark and ~bookmark-gt-update~ to point an existing one at
  the current location.  Remove any key binding to
  ~bookmark-gt-set~ from your init file: with
  ~bookmark-gt-mode~ on, ~C-x r m~ already runs
  ~bookmark-gt-create~.
- Commands renamed:
  - ~bookmark-gt-set-url~ → ~bookmark-gt-create-url~
  - ~bookmark-gt-set-function~ → ~bookmark-gt-create-function~
  - ~bookmark-gt-set-kmacro~ → ~bookmark-gt-create-kmacro~
  - ~bookmark-gt-set-sequence~ → ~bookmark-gt-create-sequence~
  - ~bookmark-gt-set-non-file~ → ~bookmark-gt-create-non-file~
  - ~bookmark-gt-set-temp~ → ~bookmark-gt-temp-set~
- Hooks renamed:
  - ~bookmark-gt-set-after-hook~ → ~bookmark-gt-record-changed-hook~.
    Functions on it now receive two arguments: the record and a
    symbol naming the operation.
  - ~bookmark-gt-set-name-reader-hook~ →
    ~bookmark-gt-create-name-reader-hook~
  - ~bookmark-gt-set-tag-reader-hook~ →
    ~bookmark-gt-create-tag-reader-hook~
- Options:
  - ~bookmark-gt-allow-duplicate-names~ →
    ~bookmark-gt-allow-same-name-bookmarks~, with the values
    ~never~, ~different-destination~ (default) and ~always~.
  - ~bookmark-gt-same-name-overwrite~ is removed.
- Creating a bookmark under a name the option does not allow is
  refused with an error.  bookmark-gt no longer renames it to
  ~NAME<2>~, and ~C-u~ on create no longer does so either.

** New

- Several bookmarks can share a name.  The list buffer and the
  jump reader show them as ~NAME<2>~, ~NAME<3>~, and so on; the
  suffix is for display only and is not saved.
- ~bookmark-gt-update~: point a bookmark at the current location,
  keeping its name, tags, annotation and visit history.
- With ~bookmark-gt-mode~ on, ~C-x r m~, ~C-x r b~, ~C-x r l~ and
  the built-in delete and rename commands run their bookmark-gt
  versions.
- ~bookmark-gt-unique-names~: names that may belong to only one
  bookmark.  Defaults to the names org-capture and org-refile
  use.
- ~bookmark-gt-unique-name-handlers~: bookmark types that keep
  one bookmark per name, so saving again replaces the previous
  one.  Defaults to burly window layouts.
- ~bookmark-gt-jump-location-max-width~: the widest the location
  column of the jump reader may grow.  Default 100.
- Sequence bookmarks keep working when a member is renamed.
- For Lisp code: ~bookmark-gt-jump-record~,
  ~bookmark-gt-rename-record~ and ~bookmark-gt-delete-record~ act
  on a record; ~bookmark-gt-relocate~ accepts a record as well as
  a name.

** Changed

- The jump reader\='s location column uses the space the other
  columns leave free, so long URLs and paths are cut less on a
  wide frame.
- ~org-refile-last-stored~ is a temporary bookmark by default,
  like ~org-capture-last-stored~, and is not saved to the
  bookmark file.
- Browser tabs are fetched only when they are about to be shown:
  when the jump reader opens or the list buffer is opened or
  refreshed.  ~bookmark-gt-browser-tabs-debounce~ is removed.
- Browser tabs sort in MRU order by when you last jumped to them
  from bookmark-gt, not by when the browser last focused them.
- Marks in the list buffer are kept when the bookmark file is
  reloaded.
- Bookmarks that break the same-name rule when the file is loaded
  are hidden, with a warning listing them.  They stay in the file
  until the next save.
- A sequence bookmark with members that no longer exist is
  reported when it is shown, instead of failing while it runs.
- Upgrading adds an identifier to every bookmark, so the first
  save after upgrading rewrites the whole bookmark file.  Built-in
  ~bookmark.el~ can still read it.

** Fixed

- All bookmarks could be erased from the bookmark file when the
  first bookmark command of a session was a save or a create.
- A package that stores bookmarks itself (org-capture, org-refile,
  burly) could overwrite one of your bookmarks of the same name,
  or erase its tags, annotation and visit history.
- Commands acting on a bookmark whose name is shared — jump,
  rename, relocate, delete, toggle-temp, auto-update toggle —
  acted on the first one with that name instead of the one
  selected.  They now ask when the choice is ambiguous.
- Jump-reader annotations were missing for ~NAME<2>~ entries, or
  showed the wrong bookmark\='s details.
- Renaming a file before the bookmark file was loaded left its
  bookmark pointing at the old path.
- ~bookmark-gt-relocate~ accepted a target of a different type,
  for example an org file for a PDF bookmark.
- Tags passed to ~bookmark-gt-create-url~ and the other create
  commands were not offered in the tag prompt.
- Refreshing browser tabs stopped at the first repeated tab
  title.
